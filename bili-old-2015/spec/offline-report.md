## 3. Rewrite rule (exact)

```
for every match of  url( 'x' | "x" | x )   (regex /url\(\s*(?:'([^']*)'|"([^"]*)"|([^)'"\s]*))\s*\)/gi)
  target = the captured group, trimmed
  if target starts with "data:"      -> leave the whole url(...) byte-identical
  if target starts with "#"          -> leave the whole url(...) byte-identical
  if target is a bare relative path  -> leave as is (already local)
  norm = strip /web/<ts>im_/ and http://web.archive.org/web/<ts>im_/ wrappers,
         "//host" -> "http://host", lowercase scheme+host, collapse // inside the path
  entry = manifest[norm] or manifest[path-of-norm]; entry counts only when status == "ok"
          and the file actually exists; otherwise fall back to assets/<path-of-norm> on disk
  if entry is local:
      base = basename(entry.path)
      inline = (base in CHROME_ALWAYS) or (entry.bytes < --inline-limit)
      inline -> url("<data:mime;base64,...>")        (quoted, because base64 contains ; , =)
      else   -> url(<relative path from the html root, e.g. assets/images/...>)
  else:
      url(<http://host/path>)   # live url, wayback wrapper removed, double slashes collapsed
```
