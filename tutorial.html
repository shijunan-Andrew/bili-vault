本地目录打开助手 · 安装教程

装好之后，收藏库里的「打开本地视频目录」就能直接在文件资源管理器里定位到视频文件夹。总共五步，装一次就行。

  1. 双击插件目录里的 install-native-folder-opener.bat

    就在你加载插件时选的那个文件夹里，和 manifest.json 放在一起。

    ← → ↑   bili-vault
    📄install-native-folder-opener.batWindows 批处理文件
    📄manifest.jsonJSON 文件
    📄library.htmlChrome HTML

  2. 在弹出的窗口里，粘贴扩展程序 ID

    先去 chrome://extensions，找到「哔哩藏库」，把插件介绍下方那串 ID 复制下来，粘贴到黑窗口里按回车。

    chrome://extensions
    哔哔哩藏库
    把 B 站收藏夹备份本地…
    ID：●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●●

  3. 再粘贴视频下载目录的绝对路径

    打开你的视频下载文件夹（默认是收藏根目录下的 000视频下载），在文件资源管理器上方的地址栏点一下，把里面的完整地址复制过来，粘贴到黑窗口里按回车。

    ← → ↑ ↻   000视频下载
    D:\本地收藏夹\000视频下载

  4. 看到「安装完成」就成功了

    窗口里会列出扩展程序 ID、宿主启动器、原生消息清单和下载目录。看到这几行就说明写进去了。

    C:\WINDOWS\system32\cmd.exe
    安装完成。
    扩展程序 ID：●●●●●●●●…
    下载目录：D:\本地收藏夹\000视频下载

  5. 完全退出 Chrome，再重新打开

    关掉所有 Chrome 窗口（必要时在任务管理器里结束 chrome.exe），然后重新打开。

    不需要重新加载插件 —— 完全重启 Chrome 就够了。重启后回到收藏库，点「打开本地视频目录」试试。
