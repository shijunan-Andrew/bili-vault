# B站收藏信息归档

这是一个 Chrome Manifest V3 扩展。它监听 B 站视频页的收藏夹弹窗；用户确认后，等弹窗成功关闭，再将视频信息和封面写入你选择的本地目录。扩展不拦截或改写 B 站页面的网络请求。

## 安装

1. 在 Chrome 打开 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目文件夹。
4. 点击工具栏中的“B站收藏信息归档”，选择本地保存文件夹。
5. 打开 B 站视频页并收藏视频。保存结果会在视频页右下角弹出。

## 保存结构

```text
所选根目录/
└── 收藏夹名称/
    └── 2026年10月08日21时05分30秒/
        ├── 封面.png
        └── 视频信息.txt
```

同一收藏夹在同一秒内发生多次保存时，后续记录目录会自动添加 `_2`、`_3` 等后缀，避免覆盖已有文件。

## 错误报告

保存失败时，扩展会尝试在所选根目录的 `错误报告` 子目录中写入报告。若目录不可访问，错误报告会留在扩展弹窗中，可通过“下载错误报告”保存到本地。

## 本地收藏库

点击扩展弹窗里的“打开本地收藏库”，首次选择归档根目录后，页面会记住该目录；之后重新打开时会自动读取，若 Chrome 要求再次授权，可继续使用上次目录，无需重新选择。页面只解析符合“根目录 / 收藏夹 / 时间戳目录 / 视频信息.txt + 封面.png”结构的视频记录，支持按收藏夹筛选、搜索、排序；点击视频卡片可查看信息并跳转到 B 站原视频。目录内容仅由浏览器在本机读取。

网页可新建或删除本地收藏夹，也可在已选收藏夹中添加视频。添加时输入 B 站视频网址、BV 号或 av 号，扩展会向 B 站查询视频标题、封面、UP 主、分区、时长、发布时间、标签和简介，并按收藏归档的相同格式写入本地。首次升级到此版本时，Chrome 会请求访问 B 站接口的权限；收藏夹和视频管理只作用于本地文件。

在视频详情中可以把本地归档移动到另一个已存在的收藏夹，也可以删除该条本地归档。移动和删除前会请求本地目录写入权限，并在网页内确认删除整个视频记录或整个收藏夹。

如果浏览器回收了本地目录的写入授权，扩展弹窗会显示“重新授权保存位置”。授权后，近期失败且已暂存的视频会自动补存；较早版本失败时没有暂存内容，需要在 B 站重新收藏一次。

## 开关与本地整理

扩展弹窗中的开关控制自动归档；开启时工具栏图标为蓝色，关闭时为灰色。关闭自动归档不会影响本地收藏库。打开视频详情后，可把归档目录移动到另一个本地收藏夹，或删除这条视频的本地归档文件；这些整理操作不会修改 B 站账户中的收藏。

## 说明

- 本地文件夹由用户在扩展弹窗中选择，浏览器会记住目录授权；授权失效时重新选择文件夹即可。
- 信息格式参照用户提供的 `内容示例.txt`。
- B 站收藏弹窗的页面结构调整后，可能需要更新弹窗检测逻辑。
