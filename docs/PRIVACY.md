# 隐私说明（哔哩藏库 Bili Vault）

> 面向商店审核与用户。**一句话：这个扩展不收集、不上传、不分析任何数据；除了向你自己的 B 站账户拉取收藏资料，它不跟任何服务器打交道。**

更新时间：2026-10-23（对应 V1.8.24）

## 1. 数据存在哪里

| 数据 | 位置 | 谁能看到 |
| --- | --- | --- |
| 视频信息、封面、归档目录 | 你自己选的「本地备份文件夹」 | 只有本机的你和能读该目录的程序 |
| 设置（外观、语言、每页条数、导入断点等） | `chrome.storage.local` | 只有这个扩展 |
| 目录句柄、背景图 | 扩展自己的 IndexedDB（`bili-fav-archiver`） | 只有这个扩展 |
| 错误报告 | 归档目录下的 `001错误报告/` | 只有你；报告正文里的盘符前路径会被掩码成 `<用户>` 之类的相对写法 |
| 统计库 | 归档目录下的 `003database/database.json` | 只有你（纯文本，可自行打开、删除） |

**没有任何一份数据会被发送到作者或第三方服务器。** 扩展里没有统计 SDK、没有埋点、没有远程日志、没有远程配置，也不加载任何远程代码。

## 2. 会发哪些网络请求

只有两类，且全部是 `GET`：

1. `https://api.bilibili.com/*` —— 读你**自己的**收藏夹列表与视频公开资料（收藏夹、视频详情、标签、UP 主粉丝数）。带浏览器里已有的 B 站登录态（`credentials: "include"`），因为收藏夹需要登录才能读。**只读，不写**：不收藏、不点赞、不投币、不关注、不发评论，扩展没有任何写操作。
2. `https://*.hdslb.com/*` —— 下载视频封面图（`credentials: "omit"`），存进本地归档。

3. `https://raw.githubusercontent.com/*` 与 `https://cdn.jsdelivr.net/*` —— **只有你点「检查更新」时**才发一次 `GET`，读本仓库公开的 `version.json`（版本号、日期、下载页、zip 的 SHA-256）。不带任何 Cookie、不带登录态（`credentials: omit` 语义），也不会上传任何东西；这两项不需要额外权限，因为对方允许跨域读取。
除这三类之外没有别的域名；不会向任何广告、统计或 CDN 服务发起请求。B 站接口的请求频率被刻意压到每秒不超过 2 次（导入时约 1.2 条/秒），避免触发 B 站的访问限制。

## 3. 每个权限用来做什么（商店审核对照）

| 权限 | 用途 | 不授予的后果 |
| --- | --- | --- |
| `storage` | 存设置、最近状态、错误报告文本、导入断点 | 设置无法保存，导入断点续跑不可用 |
| `unlimitedStorage` | 归档与统计库可能很大，避免扩展存储被配额卡住 | 大收藏夹可能写入失败 |
| `nativeMessaging` | 可选的「本地目录打开助手」（一个本机 PowerShell 宿主，需你手动安装）：只用来在资源管理器里打开归档目录 | 打不开本地目录，其余功能不受影响 |
| `clipboardWrite` | 复制路径 / 复制失败清单 | 复制按钮不可用 |
| `notifications` | 后台归档完成或失败时提示 | 没有系统通知，界面内仍会显示结果 |
| `host_permissions`: `api.bilibili.com`、`*.hdslb.com` | 见第 2 节 | 无法导入或无法下载封面 |

权限清单可以在 `manifest.json` 里逐条核对；这个仓库里**没有任何 npm 依赖、没有构建步骤**，装进浏览器的就是仓库根目录里的这些文件。

## 4. 错误报告里有什么

出错时扩展会在本地归档目录写一份 `001错误报告/*.md`，用于你自己排查。正文包含：

- 错误消息与调用栈；
- **掩码后的**路径（盘符之后的路段保留，`C:\Users\<用户名>\` 会被替换成 `<用户>`）；
- 视频链接（B 站 URL）、收藏夹名、操作名。

报告只存在本地，不会自动发送给任何人。想清空就删掉 `001错误报告` 目录里的文件，或在设置页用「清理本机的原生目录助手」旁边的清理入口。

## 5. 第三方与远程代码

- 不包含任何第三方脚本、字体、图片 CDN 或分析库；
- 不加载远程代码（MV3 要求，本扩展也没有任何 `eval` / 动态 `import`）；
- 唯一的「外部程序」是可选的原生目录助手，脚本随仓库提供、由你手动安装，只做「打开一个已存在的目录」这件事（协议只读 `settings.json`、对下载根内路径做存在性检查、用资源管理器打开）。

## 6. 删除数据

- **卸载扩展**：`chrome.storage` 与 IndexedDB 里的设置、句柄、背景图会随卸载删除；
- **本地归档**：在你自己选的文件夹里，删掉对应收藏夹目录即可（删之前建议先看一眼 `005回收站`，扩展的删除操作会先进回收站保留 30 天）；
- **错误报告与统计库**：`001错误报告/`、`002同步报告/`、`003database/` 都是普通目录/文件，直接删除即可。
