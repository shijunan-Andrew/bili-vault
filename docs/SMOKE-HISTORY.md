## V1.17.16 新增的几条

> 这一版只动导入：不再改写已有的记录。真机上验这四条。

- [ ] **报告里没有「更新记录」了**：同一批收藏连续导入两次 → 第二次的报告只有「读取视频 / 新导入 0 / 已存在跳过 N / 失败 0」，没有「更新记录」这一行。
- [ ] **已有记录一个字节都不动**：在资源管理器里看一眼某个 `视频信息.txt` 的修改时间 → 再导入一次 → 时间不变、内容不变、封面不动。
- [ ] **文案对得上**：导入完成的弹窗/通知写的是「导入完成：新导入 N 个，已存在跳过 S 个，失败 F 个。」；插件弹窗与使用说明里不再出现「已有的按最新资料刷新」。
- [ ] **「更新视频数据」照旧**：选中几条点它 → UP 主粉丝数、【互动数据】、原为「未知」的发布时间会更新，别的字段不动。

## V1.17.15 新增的几条

> 这一版只动内部两处：扫描缓存的写回方式、详情面板的模板拼装。都不改界面，真机上验这四条。

- [ ] **大库照旧扫得动**：选一个几百条以上的归档 → 打开收藏库、再点一次「刷新」→ 列表、条数、顶栏占用与改动前一致，没有报错。
- [ ] **缓存真的生效**：关掉收藏库页再打开（不刷新）→ 应很快出列表；随后在资源管理器里改一个视频的 `视频信息.txt`（比如改标题）→ 点「刷新」→ 那条标题跟着变。
- [ ] **详情面板照旧**：随便点开几条视频 → 标题、简介、BV 号、标签、互动数据、按钮位置都对；失效视频仍有「全网搜索该视频」。
- [ ] **升级后第一次扫描**：这一版第一次打开收藏库会整库重写一次缓存（正常），第二次打开应明显更快。

## V1.17.14 新增的几条

> 这一版只动两处：失联失败也登记补存、回收站页开始排队。真机上验这四条。

- [ ] **失联也会补**：在资源管理器里把本地备份文件夹改名 → 回 B 站收藏一条视频（应看到「上次选择的本地备份文件夹已经不在了…」）→ 把文件夹名字改回来 → 点插件图标：应出现「补存这条视频」的入口，点了能真的存下来。
- [ ] **授权失效照旧**：换一个需要重新授权的目录 → 收藏一条 → 提示「写入授权已失效…」→ 重新授权后同样能补。
- [ ] **回收站排队**：开一轮导入（条数挑多点）→ 导入进行中去回收站点「恢复」→ 应只出现「正在导入收藏夹，等导入结束再动回收站。」，列表一项都不动；导入结束后再点，恢复成功。
- [ ] **回收站跑完把位置让出来**：回收站恢复 / 彻底删除 / 清空各做一次之后，回收藏库删一个收藏夹仍能正常执行（不该被「回收站正在…」挡住）。

## V1.17.13 新增的几条

> 这一版只动删除路径的三处口径。真机上验这四条。

- [ ] **扫描期间按钮是灰的**：选一个大点的归档 → 点「刷新」→ 立刻看收藏夹行尾的删除按钮与顶栏「删除」：都应变灰，点不动、也不弹确认框；万一从别处点到，只出现一句「正在读取本地存档，等它读完再删除。」。
- [ ] **读完之后恢复**：扫描结束 → 收藏夹行的删除按钮可点；没有选中视频时「删除」仍是灰的（选中后才亮）。
- [ ] **同一秒删两次同名收藏夹**：造两个同名收藏夹（或删一个、立刻恢复再删）→ 两次都成功，`005回收站/<时间戳>/` 下应是 `名字` 与 `名字-2` 两份，先到的那份内容没被覆盖。
- [ ] **下载清不掉也不误报**：勾「同时删除关联的本地下载文件」，把 `000视频下载` 里对应的目录先改成只读（或用别的程序占住它）→ 删除结果应说删除成功，另附一句「清理关联下载时出错…本地归档那边已经处理完了」，而不是标题写着「删除失败」。

## V1.17.12 新增的几条

> 这一版只修「直接删除」这三个入口。真机上验这四条。

- [ ] **没有新增定时器**（顺带回归）：收藏库与统计页各放前台几分钟，不该出现自己刷新 / 自己重画（页面切回来才刷新，这是既有口径）。

## 1.9.x 功能的冒烟清单（2026-10-24 文档复审补记）

- **设置页分组**：侧栏九项都在；「导入与导出」四个按钮（导出配置 / 导入配置 / 只导外观与档位 / 导出归档元数据）都能点；「归档维护」里只剩归档体检，「回收站」是独立一栏。
- **删一条视频**：确认框写「先移进 005回收站，30 天后自动清理」，按钮是「移到回收站」；删完顶部提示「已移进回收站」。
- **回收站页**：设置页「回收站」→「查看回收站」；卡片只切换选择、点开不打开详情；选一条「恢复所选」能回原收藏夹；再删一次点「彻底删除所选」，确认框写明不可逆。
- **归档体检**：「归档维护」→「归档体检」→ `006报告/体检-<时间>.md` 生成，七个小节都在；重复点不报错。
- **统计快照自愈**：DevTools 里删掉 `chrome.storage.local` 的 `bcaStats` → 打开统计页应显示「还没有数据」和「重新读取统计库」；点它数字回来。
