一、这个插件做了什么

你在 B 站收藏一个视频时，插件会把这条视频的资料存到你自己电脑上的一个文件夹里：标题、BV 号、UP 主、封面、简介、标签、播放量、收藏时间……全部写成普通文件，不依赖这个插件也能打开看。

它做两件事：

  • 自动归档：以后每次收藏成功，自动保存资料（默认开启）。
  • 批量导入 / 更新：把已有的收藏夹整理进本地，或者只补最近几天新增的。
它只读取，不改动你的账号 插件不会取消收藏、不会点赞、不会发评论，也不会修改任何 B 站上的数据。本地删掉东西也完全不影响 B 站。

二、第一次用：三步

  1. 选择本地备份文件夹

    弹窗里点「选择本地备份文件夹」，挑一个位置（比如 D:\你的备份文件夹）。这就是本地备份文件夹，和收藏库右上角那个按钮是同一个位置，在哪边选都一样。插件会在这个文件夹下按收藏夹名建子目录。

    列表会显示每个收藏夹的条数，右上角写着「已选 N 个 · 共 M 条视频」。

    从 1.8.8 起，开始前还能选「每次最多导入多少条」：50 / 100 / 300 / 500 / 全部。名额只算本地还没有的视频（已有的跳过不占名额），导到上限就收工，想接着补就再点一次。

三、平时不用管

「自动归档」默认开启：你以后在 B 站收藏成功的那一刻，插件就把这条视频的资料存好了，不需要任何操作。

它只对「新收藏」生效 —— 已经收藏过的旧视频不会因此被补上，那些要靠第四节。

四、补旧收藏：同步最近收藏

「同步最近收藏」是给这种情形用的：你最近用手机刷到就收藏了十几条，想同步到本地，但不想为这十几条去跑一次全量导入。

同步最近收藏

只同步最近几天新收藏的视频，不用扫描整个收藏夹。适合经常用手机收藏的情况。

它靠一个前提工作：B 站的收藏夹列表接口是按收藏时间倒序返回的。所以从最新一页往后读，一旦某页里最新的条目都早于你设定的天数，后面的只会更早 —— 插件就直接收工了，通常只要一两次请求。

五、B 站上删了什么：先看差异

「先看差异」不抓视频详情，只读收藏夹列表，所以很快。它回答三个问题：

  • 新增：线上有、本地没有
  • 线上已移除：本地有、线上没了（你取消收藏了，或者视频被删了）
  • 新失效 / 已恢复：视频状态变了
先看差异

只对比收藏夹列表，不抓取每条视频的详情：1000 条约 1 分钟。导入本身要 10 分钟以上，所以建议先看一眼变了什么。

为什么它只要一分钟，导入却要十几分钟 差异只读「清单」（一次 40 条），不多问；导入要为每一条单独请求一次详情接口，而每条之间有硬性的间隔下限。读清单和读详情是两种完全不同的开销。

六、请求速度怎么选

插件代替你向 B 站发请求。请求太密会触发风控，可能让你的 IP 或账号被临时限制 —— 所以档位不是一个"快慢偏好"，而是一个安全设置。

档位存在 chrome.storage.session 里，关掉浏览器再打开就会回到「较低」（手动重载扩展也一样）。想长期用别的档位，每次开浏览器都要重新选一次。

怎么选
  • 启动浏览器后的默认档 → 「较低」（1.2 秒 + 每 8 次停 6 秒）。关掉浏览器再打开就会回到这里。
  • 第一次导入大收藏夹 → 用「较低」，分批停顿最像人翻页。
  • 不想等那 6 秒的停顿 → 手动切「标准」（0.8 秒），每次开浏览器都要再切一次。
  • 较高 / 高 → 只在你确认收藏夹很小、而且只想看差异时用。切过去会先弹一次提醒，且重开浏览器后会回到「较低」。
被风控了会怎样 插件会立即停止，并告诉你等多久再试。它不会硬撑着把剩下的请求发完 —— 那只会让限制时间更长。此时不要反复重试，等一段时间再继续。

七、收藏库里能做什么

点弹窗标题行右侧的绿色胶囊「打开本地收藏库」进入。它是一个读你本地文件夹的网页，不联网也能用。

八、失效视频怎么处理

视频失效后，B 站不会删掉它在收藏夹里的位置，而是换成一张空白占位图 —— 标题、封面、简介全都没了，只剩下「已失效视频」几个字。如果你不备份，过一段时间连"我曾经收藏过这个"都查不到。

一条重要的保护规则 导入或更新时，如果解析到的结果不如本地已有的记录（失效、标题取不到、标题是「未知」），插件会丢弃它、绝不覆盖。「未知」是占位符，不是数据。
想用失效信息去覆盖已有记录，只有手动点「更新视频数据」那一条路 —— 而它也只改视频状态，不动标题、简介和标签。

九、把本地视频放进收藏夹

1.3.0 起不再提供下载功能 出于安全考虑，插件不再请求视频流地址、也不再保存视频本体 —— 它只读取收藏夹和视频资料。你仍然可以用别的方式把视频下载到本机，再把它放进收藏夹里，收藏库同样能认出它。

把已经下载好的视频放进收藏夹，分三步：

  • 在收藏库里点开一条视频的详情，点「将下载到本地的视频放入收藏夹中」。
  • 插件会在本地备份文件夹的 000视频下载 下，按 收藏夹名\标题 - BV号\ 建好这个视频的目录，里面只放一个说明文件，没有视频内容。
  • 把你下载好的视频文件复制或移动进这个目录。

做完之后，卡片上会出现「已下载」，详情里的「打开本地视频目录」会直接跳到这个目录。

目录结构和归档目录一一对应，所以你完全可以手工建目录、手工放文件，效果一样；插件只是替你省掉找路径这一步。

十、常见问题与使用边界

导入 1000 条要多久？
「标准」档约 13 分钟，「较低」档约 32 分钟。条数越多时间线性增长，因为每条视频都要单独请求一次详情。
怎么知道被风控了？
插件会立即中止，并给出等待提示；错误报告里也会写明。此时不要反复重试，等一段时间再继续。
会动我的 B 站账号吗？
不会。插件只读取收藏夹和视频信息，不取消收藏、不点赞、不评论、不修改任何数据。
本地删了会影响 B 站吗？
不会。本地文件和 B 站账户完全独立，删除本地归档不影响线上收藏。
主题和界面语言在哪改？
在设置页的「外观」和「语言」两栏里改，改完立刻生效；收藏库右下角的齿轮也能进设置页。
怎么知道有没有新版本？
在设置页的「检查更新」里点一下，会去 GitHub 查一次当前公开版；查到新版本会给你下载页和 SHA-256，覆盖安装要你自己来，插件不会自动更新。
换电脑怎么迁移？
把整个本地备份文件夹拷过去，在新电脑上重新选择这个文件夹即可。目录结构是普通文件夹，不依赖插件。
失效视频能找回来吗？
能找回一部分信息（封面、标题），但视频本身一般无法恢复播放。详见第八节。
为什么有些封面显示"暂不可恢复"？
那是失效视频的占位图。留着它，记录才能在收藏库里显示出来，不会看起来像丢了一条。
进度条停着不动，是卡住了吗？
可能是在等限速间隔，也可能在读取下一页。真正的卡死插件会提示；实在不放心可以直接关掉弹窗再打开，进度会接着显示。

使用边界

  • 请勿滥用：插件会代替你请求 B 站接口，请求过密可能触发风控，导致 IP 或账号被临时限制。请分批、低速使用。
  • 插件不提供任何绕过 B 站权限或付费限制的能力，只读取你有权限访问的内容。
  • 所有数据存在你自己的电脑上，插件不上传任何内容，也没有自己的服务器。
  • 请遵守 B 站的服务条款，以及你所在地区关于个人备份的法律规定。
